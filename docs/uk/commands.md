# Команди порту та налагодження

[← до головної](../../README.uk.md) · [English](../en/commands.md)

Порт USB, **115200 бод**, команда — рядок із кінцем рядка. Перша літера — команда, далі аргумент без пробілу
(`c7`, `V12`). Відповіді — українською. Приймач мовчить у порт, доки з порту нічого не прийшло; після першої
команди друкує звіт щосекунди.

З комп'ютера: `python3 tools/port.py ПОРТ СЕКУНД [команда …]` — надіслати команди й показати відповіді;
`python3 tools/txlog.py ПОРТ СЕКУНД [секунда:команда …]` — записати весь друк із позначками часу й надіслати
команди в призначені секунди.

## Загальні

| Команда | Дія |
|---|---|
| `?` | усі налаштування, версія, причина останнього запуску |
| `t` / `r` | зробити плату передавачем / приймачем (перезапуск) |
| `b0` / `b1` | плата: звичайна ESP32-S3 / модуль ESP32-4848S040 (перезапуск) |
| `k<0–255>` | номер набору |
| `c<1–13>` | канал; `c0` — приймач шукає канал сам |
| `L0` / `L1` | мова написів: українська / English |
| `K` | захист: чи є ключ набору, лічильники відкинутих пакетів; `K0` — забути ключ |
| `B` | самоперевірка шифру й вимір його часу |
| `u` | перевірка екрана, ручки, сенсора, картки |
| `x<0–3>` | налагодження: апаратний AES «вхолосту» додатково до робочого |

## Передавач

| Команда | Дія |
|---|---|
| `v<швидкість>` | 0.5 1 2 5.5 11 6 9 12 18 24 36 48 54 Мбіт/с; `v0` — сама |
| `p<2–20>` | потужність, дБм |
| `q<0–3>` | якість: 0 найвища, 1 стандартна, 2 мова, 3 дальня |
| `g<0–6>` | джерело: 0 вхід, 1 тон, 2 голос, 3 голос і музика, 4 музика, 5 музика з оголошенням, 6 перевірка каналів ліво/право |
| `y<№> <знач.>` | перевірочний звук: 1 мелодія (0 — по черзі), 2 оголошення раз на N с, 3 музика під голосом, дБ, 4 пауза між повторами голосу, 5 гучність музики, 6 гучність голосу |
| `w0` / `w1` | стерео в ефір |
| `a0` / `a1` | вхід: вбудований АЦП / PCM1808 (перезапуск) |
| `m` | тиша в ефірі (пакети йдуть, звуку немає) |
| `z1` / `z0` | замовкнути в ефірі зовсім / повернутися — перевірка сну приймачів |
| `s` | знайти вільний канал |
| `h0` / `h1` / `h2` / `h3` | відхід із зайнятого каналу: вимк. / увімк. / перейти зараз / 6 с вважати «поганими» |
| `T0` / `T1` | проріджування пакетів при зайнятому ефірі |
| `A1` / `A0` | рахувати чужі передачі на своєму каналі |
| `O` | вимкнути передавач (вмикає дотик до екрана) |
| `S<назва>` | назва джерела звуку; `S` — повернути «З пульта» |
| `H` | модуль 4848: перевірка вільних виводів IO1, IO2, IO40 (25 с) |
| `D` | стан картки пам'яті |
| `Z1` / `Z0` / `Z` | запис на картку: почати / зупинити / список; `Z2`, `Z3`, `Zv<файл>` — перевірочний візерунок і його звірка |
| `F…` | файли: `Fl<тека>` список, `Fi<файл>` відомості, `Fp<файл>` в ефір, `Fs` стоп, `Fm<тека>` створити, `Fd<шлях>` видалити, `Fc<файл>\|<тека>` копіювати, `F` — що в ефірі |
| `Q` | «чорна скринька» радіо; `Q0…Q3` — до якої сходинки оживляти; `Q7 Q8 Q9 Q6` — виконати сходинку на здоровому радіо |
| `Y1`/`Y0`, `Y3`/`Y4`, `Y5…Y8` | досліди з виведенням кадру екрана |
| `Y9`, `Y10`/`Y11` | навмисно збити драйвер екрана з черги буферів; класти порції кадру, куди каже драйвер (як до 2.49) / по-своєму |

### Приймачі з передавача
| Команда | Дія |
|---|---|
| `P` | список приймачів із усіма показниками та налаштуваннями |
| `I` | першому на зв'язку — «покажи себе» |
| `E0` / `E1` | вимкнути / увімкнути його |
| `V<0–20>` | гучність |
| `W0` / `W1` | вихід «протифаза» / «два канали» |
| `N<ім'я>` | дати ім'я |
| `X` | перевірка виходу на слух (п'ять станів по 6 с) |
| `i<№>=<знач.>[@номер]` | налаштування: 0 чіткість 0–3, 1 баланс −5…5, 2 межа гучності 1–20, 3 вигляд 0–2, 4 світлодіод 0–3, 5 мова 0–2; `i9=1` / `i9=0` — перевірка навушників. Приклад: `i0=2@884A94` |
| `i7=<дБ 0…24>[@номер]` | цифрове підсилення приймача (на самому приймачі — `n10=<дБ>`); у відповіді `n7=3` — «підсилення +N дБ (зараз …)» |
| `i6=<0…3>[@номер]` | блокування ручки приймача: 0 немає, 1 меню, 2 гучність, 3 усе (на самому приймачі — `n6=<0…3>`) |
| `i20…i24=<дБ>[@номер]`, `i25=<0/1>[@номер]` | еквалайзер приймача: смуги 125 Гц, 400 Гц, 1 кГц, 2,5 кГц, 6 кГц (−12…12 дБ) і зріз низів; стан і рівень до/після — у відповіді `n7=3` |
| `e`, `e<0…4>=<дБ>`, `e5=<0/1>` | еквалайзер входу передавача: показати / смуга / зріз низів; `e9=1` — проба: діяти й на тон 1 кГц (для виміру) |
| `a0` / `a1` / `a2` | вхід: вбудований / PCM1808 / проба — PCM1808 на один запуск без головного такту (порт працює; звичайно з PCM1808 передавач у порт не друкує: такт іде виводом TXD) |
| `J` / `J1` / `J0` | запити на доступ / відкрити вікно додавання на 3 хв / закрити |
| `j<№>` | дозволити доступ приймачу зі списку запитів |
| `R<номер>` | видалити приймач із набору (`R4C3B10`) |
| `M` / `M1` / `M0` | оновлення приймачів по радіо: стан / почати / скасувати |
| `M6` / `M7` | автооновлення приймачів зі старішою прошивкою: увімкнути (так з коробки) / вимкнути |
| `M2` / `M3` / `M4` / `M5` / `M9` | оновити все з картки / переглянути теку `UPDATE` / пробне / дозволити старішу версію / примусовий прохід |

### Екран передавача без рук
| Команда | Дія |

| `U<0–5>`, `U9` | відкрити вкладку (0 головна … 5 довідка), 9 — картку |

| Команда | Дія |
|---|---|
| `d<0\|4–40>` | запас, мс (0 — сам) |
| `l<0–20>` | гучність |
| `m` | тиша |
| `o0` / `o1` | вихід: PDM / PCM5102 (перезапуск) |

| `n` | налаштування «для слуху»: чіткість, баланс, межа, вигляд, світлодіод, мова |

### Ручка без рук
Вивід сам замикається на «землю» — рівно те, що робить кнопка чи контакт енкодера.

| Команда | Дія |
|---|---|
| `n8=1` | налаштування виводу кнопки (вид переривання, чи дозволене, чи будить зі сну) і лічильники сну |
| `n8=<мс>` (від 50) | натиснути на стільки мілісекунд: 300 — натискання, 1000 — довге (відкриє меню) |
| `n8=3` / `n8=4` | повернути на один клац в один і в другий бік |
| `n8=5` | натиснути на секунду, не затримуючи головний цикл |
| `n8=6` | те саме через 30 с — перевірка пробудження зі сну (уві сні порт не слухає) |
| `n8=7` | що на виводах виходу звуку: частка одиниць і перепади на 10 (SCK), 11 (BCK), 12 (LRCK), 13 (дані), 17, 18 (PDM); рівень XSMT (вивід 14) |
| `n8=9` | «логічний аналізатор»: знімає BCK, LRCK і дані з виводів (ЦАП на цей час приглушено, на вихід ідуть відомі числа 0x5A01 / 0xA5F3) і друкує біти одного слова — видно формат і зсув |
| `n8=8` | справжні частоти за час від попереднього такого виклику: звук з ефіру (годинник передавача) і вихід (свій годинник), у відліках за секунду та ppm |
| `n8=2` | лишити вивід «брудним», як після сну в старих версіях (перевірка очищення при запуску) |

## Налагодження по радіо
На передавачі: «Налашт.» → «Налагодження ефіром» або `G1` (вимкнути — `G0`). Після цього рядки порту приймачів
видно в порту передавача з номером: `[884A94] ПРИЙМАЧ к=7 …`. Команда іншому пристрою набору:

```
@884A94 ?        приймачу з цим номером
@tx u            передавачу (з порту приймача)
@* ?             усім
```

Пакети налагодження закриті ключем набору; команда чинна лише свіжа.

## Щосекундний звіт

Передавач:
```
ПЕРЕДАВАЧ к=7 шв=5.5 як=найвища набір 1 | пакетів 500, відмов 0, не пішло в ефір 0, перезапусків радіо 0,
до ефіру сер. 1600 макс. 6300 мкс | …
```
- *відмов* — драйвер не взяв пакет (черга повна); *до ефіру* — скільки пакет чекав вільного ефіру: середнє понад
  ~10 мс або максимум понад ~60 мс — ефір зайнятий.

Приймач:
```
ПРИЙМАЧ к=7 набір 1 | кадрів 500, відновлено 0, втрачено 0, порожньо 0.0 мс, зсувів 0, перезапусків 0, з копій 0 |
запас 10.6 мс (9.0…12.1, ціль 10.6 сам), темп +68 ppm | сигнал -37 дБм | рівень -11.5 дБ …
екран: 62 кадрів за секунду, передача кадру сер. 2.7 мс, найдовша 6.7 мс, обмін 800 кГц
```
- *відновлено* — кадри, взяті із запасних копій; *втрачено* — не відновлені (чути як коротку тишу);
  *порожньо* — скільки мілісекунд запас був порожній; *зсувів* — запас переповнився й був скинутий;
  *перезапусків* — приймання починалося заново; *з копій* — навмисне проріджування передавача (не втрати);
  *темп* — наскільки приймач підганяє свій хід під передавач.

## Інструменти вимірювань (`tools/`)

| Інструмент | Що робить |
|---|---|
| `port.py` | порт: надіслати команди, показати відповіді |
| `txlog.py` | весь друк плати у файл із часом + команди за розкладом |
| `watch.py`, `watch2.py` | передавач (і приймач) поруч: підсумок за N секунд — очікування ефіру, відмови, провали |
| `duo.py`, `trio.py`, `kwatch.py` | виміри з двох-трьох боків, перевірка зміни ключа |
| `sleeptest.py` | сон і пробудження приймачів за розкладом команд: `sleeptest.py ПОРТ 4:z1 26:z0 конец:42` |
| `qsweep.py` | порівняння якостей і швидкостей: `qsweep.py ПОРТ СЕКУНД якість:швидкість[:потужність] …` |
| `sweep.py`, `hoptest.py` | порівняння каналів, перевірка переходу на канал |
| `fliptest.py`, `idletest.py` | плавність перегортання сторінок і спокій екрана передавача |
| `sendfile.py` | покласти файл на картку передавача через порт |
| `langtest.py` | перевірка перекладу |
| `linktest/` | окрема прошивка перевірки радіоканалу на «голих» платах |
